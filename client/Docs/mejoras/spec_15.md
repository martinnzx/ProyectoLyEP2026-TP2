# Especificación de Mejora: Corrección de Dashboard para ajustarse al contenido registrado en la base de datos

## 1. Propósito

Definir la mejora necesaria para que el dashboard muestre datos actualizados a partir de los registrados en la base de datos.


## 2. Problema actual

- Actualmente muestra datos estáticos, se trata de cambiar dicha situación para terminar de darle forma a la modificación realizada hasta el momento.

## 3. Alcance

### Incluido

- Cantidad de clientes: Debe contar la cantidad total de clientes cargados.
- Gerencia: Debe contar la cantidad de usuarios del sector Gerencia.
- Soporte: Debe contar la cantidad de usuarios del sector Soporte.
- Los resultados de este proceso deben actualizar el documento doc_15.md.
- Al final de la corrección se deberá agregar al final del archivo dia.md un par de renglones descriptivos a modo de agenda de tareas.
